Server login

Unknown

Sends /login or /register to the server as Ender. Your password goes straight to the server — it is never stored, logged or written to disk, and the field is cleared immediately after sending.

Good to know

  • Connect Ender first — authentication is only possible once the bot has joined the world.
  • The login status is detected from the server’s own messages, so it may read “Unknown” on servers that word things differently.
  • Passwords cannot contain spaces. Registration repeats the password once, the way most servers expect.
  • Attempts are rate limited to respect server authentication limits. Too many wrong tries can get an account kicked or banned.
Disconnect Ender to change these settings.
